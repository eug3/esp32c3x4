# XT-E-Ink 水墨屏刷新模式分析

## 1. 概述

本文档详细分析了基于 **ESP32-C3** 芯片的 **XT-E-Ink** 水墨屏设备的刷新模式，包括**快刷（Partial Refresh）**和**全刷（Full Refresh）**的命令序列、参数配置和使用场景。

### 设备信息

| 属性 | 值 |
|------|-----|
| **芯片型号** | ESP32-C3 |
| **水墨屏型号** | XT-EPD |
| **设备标识** | E-Paper1 / e-paper1 |
| **固件版本** | V3.0.8 |
| **文件系统** | SPIFFS |

## 2. 水墨屏刷新命令详解

### 2.1 核心命令字节汇总

| 命令字节 | 功能描述 | 刷新模式 | 说明 |
|---------|---------|---------|------|
| **0x20** | Master Activation | 全刷 | 主激活命令 |
| **0x22** | Display Update Control 2 | 全刷/快刷 | **关键命令**，控制刷新参数 |
| **0x24** | Write RAM | 全刷/快刷 | 写入显示数据 |
| **0x26** | Write VCOM Register | 全刷 | 写入 VCOM 电压寄存器 |
| **0x70** | Partial In | 快刷 | 部分刷新开始 |
| **0x71** | Partial Out | 快刷 | 部分刷新结束 |
| **0x82** | Set Refresh | 快刷 | 设置刷新操作 |
| **0x90** | Partial Window | 快刷 | 设置部分刷新窗口 |
| **0xA0** | B/W Lookup Table | 全刷 | 黑白查找表 |
| **0xA1** | Red Lookup Table | 全刷 | 红色查找表（三色屏） |
| **0xA2** | Write LUT Register | 全刷 | 写入查找表寄存器 |
| **0xC0** | Analog Control | 全刷 | 模拟控制 |
| **0xC1** | Temp Sensor Control | 全刷 | 温度传感器控制 |
| **0xC2** | Write Digital Control | 全刷 | 写入数字控制寄存器 |

## 3. 全刷模式（Full Refresh）

### 3.1 命令序列

```
全刷模式完整命令序列：

1. 0x20 - Master Activation
   └─ 激活水墨屏主控制器

2. 0xC0 - Analog Control
   └─ 设置模拟控制参数

3. 0xC2 - Write Digital Control
   └─ 写入数字控制寄存器

4. 0xA0 - B/W Lookup Table
   └─ 加载黑白查找表（LUT）

5. 0xA2 - Write LUT Register
   └─ 写入查找表寄存器

6. 0x24 - Write RAM
   └─ 写入完整的屏幕图像数据（全屏像素）

7. 0x22 - Display Update Control 2
   └─ 设置刷新参数并触发刷新

8. 0x26 - Write VCOM Register
   └─ 写入 VCOM 电压寄存器
```

### 3.2 关键命令参数

#### **0x22 - Display Update Control 2**

```
参数格式：
Bit 7  Bit 6  Bit 5  Bit 4  Bit 3  Bit 2  Bit 1  Bit 0
[ 保留 ] [ 保留 ] [ 保留 ] [ 模拟 ] [ 时钟 ] [ 模式2 ] [ 模式1 ] [ 模式0 ]

模式参数（Bit 0-2）：
  000 = 初始化模式
  001 = 全刷模式
  010 = 快刷模式
  011 = 清除模式
  100-111 = 保留
```

#### **0x90 - Partial Window**（用于快刷）

```
参数格式（5 字节）：
Byte 0: 起始 X 坐标高 8 位
Byte 1: 起始 X 坐标低 8 位
Byte 2: 起始 Y 坐标
Byte 3: 窗口宽度
Byte 4: 窗口高度

窗口坐标系统：
  (0, 0) = 左上角
  (max_x, max_y) = 右下角
```

### 3.3 全刷特点

| 特性 | 描述 |
|------|------|
| **刷新范围** | 整个屏幕 |
| **查找表** | 使用完整 LUT（0xA0, 0xA2） |
| **刷新时间** | 2-3 秒（取决于屏幕尺寸） |
| **画质** | 高对比度，清晰无残影 |
| **功耗** | 较高（需要驱动整个屏幕） |
| **温度补偿** | 包含温度传感器控制（0xC1） |
| **VCOM 调整** | 包含 VCOM 电压设置（0x26） |

## 4. 快刷模式（Partial Refresh）

### 4.1 命令序列

```
快刷模式完整命令序列：

1. 0x70 - Partial In
   └─ 标记部分刷新开始

2. 0x90 - Partial Window
   └─ 设置刷新窗口坐标和大小
   └─ 参数：x_start (2 bytes) + y_start + width + height

3. 0x24 - Write RAM
   └─ 仅写入窗口区域的图像数据

4. 0x82 - Set Refresh
   └─ 触发刷新操作

5. 0x71 - Partial Out
   └─ 标记部分刷新结束
```

### 4.2 快刷特点

| 特性 | 描述 |
|------|------|
| **刷新范围** | 指定窗口区域 |
| **查找表** | 不使用完整 LUT，使用简化算法 |
| **刷新时间** | 100-300ms（取决于窗口大小） |
| **画质** | 对比度略低，可能有轻微残影 |
| **功耗** | 较低（只驱动部分像素） |
| **窗口限制** | 部分屏幕不支持过于频繁的快刷 |

## 5. 两种模式对比

| 特性 | 全刷（Full Refresh） | 快刷（Partial Refresh） |
|------|---------------------|------------------------|
| **命令开头** | 0x20, 0xC0, 0xC2 | 0x70, 0x90 |
| **查找表** | 使用完整 LUT (0xA0, 0xA2) | 不使用 LUT |
| **刷新范围** | 整个屏幕 | 指定窗口区域 |
| **刷新时间** | 2-3 秒 | 100-300ms |
| **画质** | 高对比度，清晰 | 略低，可能有残影 |
| **功耗** | 较高 | 较低 |
| **连续刷新** | 需要间隔（避免损坏屏幕） | 可以频繁刷新 |
| **温度补偿** | 包含（0xC1） | 不包含 |
| **VCOM 调整** | 包含（0x26） | 不包含 |
| **命令数量** | 8 个命令 | 5 个命令 |
| **数据量** | 全屏像素数据 | 窗口像素数据 |

|--------|---------|------|------------|

| **readNight** | 0x2f00 | 夜间读取配置 | - |
| **readFont** | 0x2f0c | 字体读取配置 | - |

### 6.2 关键配置说明

#### **fullBrushInterval（全刷间隔）**
```
配置项：fullBrushInterval
类型：整数（毫秒）
默认值：未明确，建议 500-1000ms
说明：
  - 控制全刷和快刷之间的间隔
  - 范围：200ms（最小）- 5000ms（最大）
  - 过于频繁的全刷会缩短屏幕寿命
  - 过长的间隔会导致明显的残影累积
```

#### **eepromUser 命名空间**
```
配置项：eepUser
类型：NVS 命名空间
说明：
  - 存储用户自定义设置
  - 包括刷新参数、按键映射等
  - 保存设备型号标识符
  - 存储 ADC 按键校准值
```

## 7. 实际使用场景

### 7.1 全刷（Full Refresh）使用场景

| 场景 | 说明 |
|------|------|
| **翻页显示** | 阅读器翻页时，显示新页面内容 |
| **首次开机** | 设备启动时初始化显示 |
| **消除残影** | 累积 5-10 次快刷后执行一次全刷 |
| **显示高质量图像** | 需要高对比度和清晰度的图像 |
| **长时间不操作** | 屏幕长时间未更新，全刷刷新整个屏幕 |
| **切换应用/模式** | 从一个功能切换到另一个功能时 |

### 7.2 快刷（Partial Refresh）使用场景

| 场景 | 说明 |
|------|------|
| **更新进度条** | 阅读进度、下载进度等 |
| **显示小图标** | WiFi 图标、蓝牙图标等状态指示 |
| **时间显示更新** | 时钟时间变化 |
| **光标移动** | 输入法光标、选择框焦点移动 |
| **状态指示灯** | 电池状态、连接状态等 |
| **滚动文本** | 通知消息滚动显示 |
| **菜单项高亮** | 菜单选择项变化 |

### 7.3 混合刷新策略

```
推荐的刷新策略：

1. 初始化阶段：
   └─ 使用全刷显示启动画面

2. 主要操作阶段：
   └─ 主要使用快刷更新小区域
   └─ 每 5-10 次快刷后执行一次全刷

3. 切换内容阶段：
   └─ 使用全刷显示新内容

4. 长时间待机后：
   └─ 使用全刷刷新整个屏幕

5. 错误处理：
   └─ 检测到显示异常时，使用全刷恢复
```

## 9. 技术细节

### 9.1 SPI 通信接口

```
水墨屏通过 SPI 接口与 ESP32-C3 通信：

SPI 引脚配置（推测）：
  - MOSI: 数据输出（从 MCU 到屏幕）
  - SCLK: 时钟信号
  - CS: 片选信号
  - DC: 数据/命令选择
  - RST: 复位信号
  - BUSY: 忙状态信号

通信流程：
  1. 拉低 CS 选中屏幕
  2. 发送命令字节（8 位）
  3. 如果需要，发送参数/数据
  4. 拉高 CS 取消选中
  5. 等待 BUSY 信号变低（刷新完成）
```

### 9.2 状态检测

```
BUSY 状态信号：
  - 高电平：屏幕正在刷新，不接受新命令
  - 低电平：屏幕空闲，可以发送新命令

超时检测：
  - 如果 BUSY 超过预计时间未变低
  - 报告 "Busy Timeout!" 错误
  - 执行复位操作
```

### 9.3 查找表（LUT）说明

```
LUT（Look-Up Table）作用：
  - 定义每个像素从当前灰度到目标灰度的驱动波形
  - 包含 256 个灰度级别的转换表
  - 影响刷新速度、对比度和残影

全刷 LUT 特点：
  - 完整的 256 级灰度查找表
  - 优化的波形，确保高质量刷新
  - 刷新时间较长但画质好

快刷模式：
  - 不加载完整 LUT
  - 使用简化的线性驱动或预设波形
  - 刷新时间快但对比度略低
```

## 10. 故障诊断

### 10.1 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| **残影严重** | 快刷过于频繁，未及时全刷 | 调整 fullBrushInterval，增加全刷频率 |
| **刷新超时** | BUSY 信号异常或 SPI 通信失败 | 检查 SPI 接线，验证屏幕硬件 |
| **显示异常** | LUT 数据错误或命令序列错误 | 重新发送完整的全刷命令序列 |
| **部分区域不刷新** | 窗口坐标计算错误 | 验证 0x90 命令的参数 |
| **对比度过低** | 温度传感器数据异常 | 检查 0xC1 命令和温度补偿 |

### 10.2 调试建议

```
调试步骤：

1. 检查 BUSY 信号：
   - 使用示波器观察 BUSY 引脚
   - 验证刷新时间是否符合预期

2. 验证 SPI 通信：
   - 抓取 SPI 总线数据
   - 确认命令和参数正确发送

3. 测试命令序列：
   - 先测试简化版本（如仅发送 0x20 和 0x26）
   - 逐步添加命令，定位问题命令

4. 监控 VCOM 电压：
   - 验证 0x26 命令的参数
   - 确保在屏幕规格范围内

5. 检查 LUT 数据：
   - 验证 0xA0 和 0xA2 命令后的数据
   - 确保查找表数据完整正确
```

## 11. 性能优化建议

### 11.1 刷新频率优化

```
优化原则：

1. 合理设置 fullBrushInterval：
   - 对于频繁更新的小区域，使用较长间隔（1000-2000ms）
   - 对于需要高对比度的场景，使用较短间隔（500-1000ms）

2. 累积快刷次数：
   - 维护一个快刷计数器
   - 每 N 次快刷后自动触发一次全刷

3. 智能区域刷新：
   - 对于重叠的更新区域，合并为一个快刷窗口
   - 减少不必要的刷新操作
```

### 11.2 功耗优化

```
功耗优化策略：

1. 合理使用快刷：
   - 对于频繁更新的小元素（时钟、图标），使用快刷
   - 避免不必要的小范围全刷

2. 批量更新：
   - 将多个小更新合并为一个较大的快刷窗口
   - 减少刷新次数

3. 静默期管理：
   - 在长时间无操作时，降低刷新频率
   - 进入低功耗模式
```

## 12. 总结

### 12.1 关键要点

| 要点 | 说明 |
|------|------|
| **两种刷新模式** | 全刷（高质量，慢速）和快刷（快速，略低质量） |
| **核心命令** | 0x20, 0x22, 0x24, 0x70, 0x71, 0x82, 0x90, 0xA0, 0xA2, 0xC0, 0xC2 |
| **关键区别** | 全刷使用完整 LUT，快刷不使用 LUT |
| **使用策略** | 混合使用：快刷用于频繁更新，全刷用于内容切换和残影消除 |
| **配置参数** | fullBrushInterval 控制全刷间隔（200-5000ms） |
| **故障处理** | 监控 BUSY 信号，检测超时和异常 |

### 12.2 最佳实践

```
推荐的刷新策略：

1. 内容切换时使用全刷：
   - 翻页
   - 打开新文件
   - 切换应用

2. 频繁更新使用快刷：
   - 进度条
   - 状态图标
   - 时间显示
   - 光标移动

3. 定期全刷消除残影：
   - 每 5-10 次快刷后
   - 长时间无操作后
   - 检测到残影时

4. 合理配置刷新间隔：
   - 根据使用场景调整 fullBrushInterval
   - 平衡刷新质量和响应速度
   - 避免过于频繁的全刷
```
